# L4D2 appearance mod — offline DayZ playtest

Download the ZIP from [Releases](https://github.com/jubjub-cpu/l4d2-dayz-offline-test/releases), extract the whole archive, leave Steam signed in, and double-click **PLAY OFFLINE.cmd**.

The package starts an offline Cherno playground with 30 varied infected, a loaded MP5, replenishing ammo, 30-second infected respawns and automatic player respawn. No server setup is needed.

Infected use normal DayZ AI with locally converted L4D2 common/uncommon models and textures. An optional addon supplies original L4D2 neutral idles. Special-infected abilities and Source AI are outside this package.

Use legitimate copies of DayZ and Left 4 Dead 2. See the included README for controls, optional native-idle mode, local mod/server use and test limitations.

The ZIP is published as a release asset. This repository contains delivery instructions, not proprietary asset files in Git history.
